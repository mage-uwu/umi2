umi answers from a cache, and can show its answers as cards, charts and dashboards.

Each message goes through a 1,287,904-parameter bidirectional SSM. It fills a masked three-byte answer ID that picks one of 17,984 replies DeepSeek wrote for umi. Follow-ups use umi's last two replies as context. Your name is swapped for a <regex>user_name</regex> tag before the model reads it, and filled back in afterwards.

A second model, umi-smart-internet, picks one of 3,757 HTML widgets when a message asks for something visual. Ask for a recipe card, a chart or a habit tracker, or say "put that in a card" or "make it a flashcard" to restyle umi's last reply. Everything runs on this device; nothing you type leaves the page.
