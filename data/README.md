Unseen evaluation plays: public-domain texts from Project Gutenberg (Marlowe, *Doctor Faustus*
and *Tamburlaine the Great, Part 2*; Kyd, *The Spanish Tragedie*). Gutenberg headers, footers and
footnote markers are removed, and speech headings are rewritten to TinyShakespeare's `NAME:` line
format by `experiments/normalize_gutenberg.py`.
None of this text is in TinyShakespeare.
