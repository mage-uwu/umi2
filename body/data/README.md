# motions_ref.bin

Reference poses for the physics character, converted by `tools/motions_to_ref.py` from the ANIME NEURAL SHADER
page's `motions.json`, which retargets clips of the **Bandai Namco Research Motion Dataset**
(https://github.com/BandaiNamcoResearchInc/Bandai-Namco-Research-Motiondataset), licensed **CC BY-NC 4.0**.
This derived file carries the same licence: attribution required, non-commercial use only.

Clips: walk, bye, byebye, bow, guide, run, dance (30 fps).
